# 🎵 Spotify Music Analytics Dashboard

An interactive, Spotify-inspired dashboard built with **Microsoft Power BI** to explore its visualization capabilities and develop better dashboard design skills.

<img width="1322" height="740" alt="2)Overview_page" src="https://github.com/user-attachments/assets/8b5c189f-22fc-4d4c-bb60-a178adffcf6c" />

## 🎯 Project Purpose

The main goal of this project was to explore Power BI more deeply, experiment with its interactive features, and improve my understanding of **UI/UX design for data presentation**. The focus was on creating a visually appealing, intuitive, and interactive dashboard rather than demonstrating a complete data analytics workflow.

## 📊 Dashboard Pages

- **Home:** Custom-designed landing page with navigation.
- **Overview:** Music statistics, KPIs, and trends.
- **Artists:** Artist performance and popularity insights.
- **Songs:** Song-level metrics and detailed data tables.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query and DAX
- Figma (background and visual design)

## 🎨 Design Focus

Custom backgrounds, Spotify-inspired styling, interactive navigation, KPI cards, charts, album artwork, and consistent visual layouts.
